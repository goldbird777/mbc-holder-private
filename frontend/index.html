⛏️ 채굴 방법 소개
MBC를 직접 채굴해보고 싶은 분들을 위한 입문 가이드

MBC 채굴이 특별한 이유

MicroBitcoin은 Power2B 알고리즘을 사용해 ASIC 채굴기 없이 일반 CPU로 채굴할 수 있습니다. 사토시 나카모토가 비트코인 백서에서 강조한 "1-CPU-1-Vote" 원칙을 실제로 구현한 몇 안 되는 코인입니다.

데스크톱 PC는 물론 안드로이드 스마트폰에서도 채굴이 가능하며, 누구나 네트워크에 참여할 수 있습니다.

⚠️ 본 가이드는 정보 제공 목적이며 채굴로 인한 전기 요금, 하드웨어 발열·손상, 배터리 소모 등의 책임은 본인에게 있습니다. 수익성은 시세와 네트워크 난이도에 따라 변동하며 손실 가능성이 있습니다.

💻 PC에서 채굴하기

1단계: MBC 지갑 주소 준비

채굴 보상을 받을 본인 지갑 주소가 필요합니다. 공식 웹지갑 또는 Wonpay 모바일 지갑에서 주소를 생성하세요. (B로 시작하는 문자열)

2단계: cpuminer-opt 다운로드

cpuminer-opt GitHub Releases에서 본인 OS(Windows/Linux/Mac)에 맞는 최신 버전을 다운로드합니다.

3단계: 채굴 풀 선택

소규모 채굴자는 zpool.ca를 추천합니다. 다른 사람들과 해시를 합쳐 안정적으로 보상을 받을 수 있습니다.

  • 풀 주소: stratum+tcp://power2b.mine.zpool.ca:6242
  • 알고리즘: power2b
  • 지급 코인: c=MBC,zap=MBC
4단계: 채굴 명령어 실행

cpuminer 폴더에서 다음과 같이 실행:

cpuminer.exe -a power2b -o stratum+tcp://power2b.mine.zpool.ca:6242 -u 본인_MBC_지갑주소 -p c=MBC,zap=MBC -t 4 --no-color

-t 4는 사용할 CPU 스레드 수입니다. 본인 PC 코어 수에 맞게 조정하세요.

5단계: 보상 확인

zpool.ca 사이트에서 본인 지갑 주소로 검색하면 채굴 통계와 잔액을 볼 수 있습니다. 최소 지급액 도달 시 자동으로 본인 지갑으로 전송됩니다.

📱 안드로이드 폰에서 채굴하기

MBC는 ARM CPU 친화 알고리즘이라 스마트폰에서도 채굴이 가능합니다. 다만 발열·배터리 소모가 크니 충전 중에만 권장합니다.

권장 앱: MBC Miner (직접 배포)

Play Store는 채굴 앱을 금지하므로 GitHub에서 직접 APK를 받아야 합니다.

📥 APK 다운로드 링크 안내 보기

⚠️ 안드로이드 출처를 알 수 없는 앱 설치 허용이 필요합니다. APK 파일은 본인의 책임 하에 설치하세요. Google Play Store 외부에서 받는 앱은 항상 신중히 검토해야 합니다.

💰 수익성에 대한 현실적인 안내

솔직히 말씀드리면 MBC 채굴의 수익성은 낮습니다:

  • 갤럭시 S24 기준 약 30~40 H/s
  • 일반 데스크톱 PC 기준 약 600~1,000 H/s
  • 하루 24시간 채굴해도 시세 기준 매우 적은 보상
  • 전기 요금이 수익보다 클 가능성이 큼

그럼에도 채굴을 추천하는 이유는 네트워크 참여 경험과 학습 가치 때문입니다. 비트코인이 ASIC에 점령된 지금, 일반인이 직접 PoW 블록체인에 참여할 수 있는 거의 유일한 기회입니다.

📱 Wonpay 모바일 지갑이란?

Wonpay는 MicroBitcoin(MBC)을 모바일에서 손쉽게 보관·송수신할 수 있는 공식 지갑 앱입니다. Android와 iOS 모두 지원하며, 지갑 생성·복구·QR 송수신·잔액 확인 등 기본 기능을 모두 제공합니다.

⚠️ 웹사이트(wonpay.io)는 현재 접속이 불가하지만, 앱은 정상 운영 중입니다. 아래 공식 스토어 링크에서 안전하게 다운로드하세요.

✨ 주요 기능

  • 지갑 생성/복구 — 시드 구문(니모닉)으로 안전하게 백업
  • MBC 송수신 — QR 코드로 빠르고 간편한 거래
  • 잔액 확인 — 실시간 잔액 및 거래 내역 조회
  • 주소록 — 자주 쓰는 지갑 주소 저장
  • 토큰 지원 — MBC 기반 토큰(SATOSHI 등) 보유 확인

🔐 안전한 사용을 위해

지갑 사용 시 반드시 지킬 것:
  • 시드 구문(니모닉)은 절대 노출 금지 — 종이에 적어 오프라인 보관 권장
  • 스크린샷·클라우드 메모·이메일 등 디지털 저장은 해킹 위험
  • 본인 외 누구에게도 시드 구문을 알려주지 마세요 (개발자도 묻지 않습니다)
  • 앱은 반드시 위 공식 스토어 링크에서만 다운로드
  • 큰 금액은 콜드월렛(오프라인) 보관 권장

❓ 자주 묻는 질문

Q. 시드 구문을 잊어버렸어요

아쉽게도 복구가 불가능합니다. Wonpay는 비수탁(non-custodial) 지갑이라 개발자도 사용자의 시드를 가지고 있지 않습니다. 새 지갑을 만들고 이전 시드는 분실로 처리됩니다.

Q. 다른 기기에서 같은 지갑을 쓰고 싶어요

새 기기에 Wonpay 앱을 설치한 뒤 "기존 지갑 복구"를 선택하고 시드 구문을 입력하면 같은 지갑이 복구됩니다.

Q. 송금이 안 와요

MicroBitcoin 홀더 탐색기란?

본 사이트는 마이크로비트코인(MBC) 네트워크의 전체 홀더 정보를 누구나 쉽게 조회할 수 있도록 만들어진 커뮤니티 운영 익스플로러입니다.

MBC 풀노드를 직접 운영하며, 블록체인 데이터를 실시간으로 스캔해 모든 활성 주소와 잔액, 토큰 보유 현황을 표시합니다.

주요 기능

  • 전체 홀더 리스트: 25,000+ 활성 주소 잔액순 정렬
  • 주소 상세 조회: 거래 내역, 토큰 보유, 입출금 기록
  • 실시간 동기화: 분당 1블록 자동 반영
  • CSV 다운로드: 데이터 전체 내려받기 가능
  • API 제공: 개발자용 REST API (/api/holders)

기술 스택

  • MicroBitcoin Core 풀노드 (microd)
  • Node.js + Express API 서버
  • nginx 정적/리버스 프록시
  • Oracle Cloud Always Free Tier

면책

본 사이트는 MicroBitcoin 공식 단체와 무관한 커뮤니티 운영 사이트입니다. 표시되는 정보는 정확성을 보장하지 않으며, 투자 권유 또는 금융 자문이 아닙니다.

관련 공식 자료는 microbitcoin.org 및 GitHub MicroBitcoinOrg를 참고하세요.
